CLI et serveur MCP

Pour les agents

La CLI et le serveur MCP permettent à un agent de choisir, vérifier, créer et exporter une mascotte depuis son propre environnement.

Commandes CLI

Explorer et exporter 
python -m mascotforge styles
python -m mascotforge code --engine blob --set shape=cloud --out ./mon-blob
python -m mascotforge code --engine 3d --set character=volt --out ./mon-robot
Construire un blob sur mesure 
python -m mascotforge blob guide --out ./guide-blob.md
python -m mascotforge blob check ./blob.json
python -m mascotforge blob preview ./blob.json --out ./planche.png
python -m mascotforge blob export ./blob.json --out ./blob-sur-mesure
Construire une fiche 3D 
python -m mascotforge spec guide --out ./guide-wobnimo.md
python -m mascotforge spec check ./personnage.json
python -m mascotforge spec preview ./personnage.json --out ./planche.png
python -m mascotforge spec export ./personnage.json --out ./personnage-3d
Lancer une création IA 
python -m mascotforge image3d ./robot.png --out ./robot-3d
python -m mascotforge video --image ./robot.png --usage agent --out ./robot-video
Démarrer le serveur MCP 
python -m mascotforge mcp
Installer le skill dans ton projet 
python -m mascotforge skill

Adresse et clés

MASCOTFORGE_URL définit l'adresse du serveur, par défaut http://localhost:8766.

MASCOTFORGE_FAL_KEY devient l'en-tête X-Fal-Key. MASCOTFORGE_OPENROUTER_KEY devient X-OpenRouter-Key. Le choix de lecture d'image utilise X-Vision-Provider: fal|openrouter. Les clés ne vont jamais dans l'URL.

Codex CLI et application

Les deux lisent ~/.codex/config.toml. Codex CLI 0.144.6 accepte le champ cwd ci-dessous. La commande codex mcp add n'a pas de drapeau --cwd, donc utilise ce bloc. Sans cwd, ajoute le dépôt à PYTHONPATH dans env.

Configuration MCP 
[mcp_servers.mascotforge]
command = 'C:\Users\Darius\Desktop\text-to-mascot\.venv\Scripts\python.exe'
args = ["-m", "mascotforge", "mcp"]
cwd = 'C:\Users\Darius\Desktop\text-to-mascot'
env = { MASCOTFORGE_URL = "http://localhost:8766" }
